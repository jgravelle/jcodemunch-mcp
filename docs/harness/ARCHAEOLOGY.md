### Scars worth naming (odd inputs that are wounds)

- `tests/test_server.py` pins `len(tools) == 90` as a literal while the live `full` profile serves 91; its docstring says `test_summarizer` is disabled by default. A literal count is a second copy of the surface; flagged for the coverage map, not changed.
- `tests/test_suggest_queries.py` empty-index case is conditional and can pass vacuously.
- `tests/test_nesting_depth_channels.py` scans for a stray 0x08 BACKSPACE byte because one once replaced a backslash in a regex and compiled.
- `tests/test_v1_108_84.py` carries a real reporter's macOS path as the INPUT; the path is the defect's shape (#357), not an environment leak.
- `tests/test_watcher_serve.py` uses a literal Windows system path as a MOCKED fixture because #447 wrote a real file into a real system directory once.
- `tests/test_schema_baseline_transcription.py` fails if any literal from `schema_baseline.json` appears in `tests/` or `benchmarks/` — a guard against the number being hand-typed.
- `tests/test_optional_dep_skips_are_visible.py` forbids module-scope `importorskip` so optional-dependency tests still COLLECT and show as skips, after 105 tests vanished silently at exit 0 (2026-08-28).
- `tests/test_ci_env_reproduce_command.py` binds a command in CLAUDE.md to the workflow's install line, because the gitignored release skill drifted from CI.

## A. Methodology rules (R1..R62)

Each rule quotes its source. "file:line" is the current tree.

### Corpus selection and pinning
- **R1** Corpus is pinned by upstream COMMIT, not branch. `benchmarks/METHODOLOGY.md:14-15` — "All repositories are public and pinned to a specific upstream **commit**, not to a branch. No filtering or cherry-picking of files was applied beyond jcodemunch's standard skip patterns".
- **R2** Pins live in `tasks.json` and are re-checked every run; a mismatch refuses publication. `METHODOLOGY.md:24-27` — "the harness refuses to overwrite the published artifact when a measured index reports a different `git_head`, or when its corpus completeness is anything other than `True`."
- **R3** `index_repo` is banned for the benchmark because it cannot pin. `METHODOLOGY.md:156-158` — "`index_repo` is deliberately NOT used here: it has no ref parameter and always fetches whatever the default branch points at today, so it cannot reproduce a pinned corpus."

- **R5** Do not lower the file cap. `REPRODUCING.md:52-56` — "**Do not lower the file cap.** ... A lower cap truncates silently — the harness will refuse to publish the result ... but only because that refusal was added in v1.108.222."
